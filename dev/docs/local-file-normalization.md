| Form (examples)                                                                                                        | OS      | Type                                    | Ideal normalized form (mdview:file://…)                                                           |
| ---------------------------------------------------------------------------------------------------------------------- | ------- | --------------------------------------- | ------------------------------------------------------------------------------------------------- |
| `subdir\docs\spec.md`<br>`subdir/docs/spec.md`                                                                         | Both    | Relative path                           | `mdview:file:///<BASE_DIR>/subdir/docs/spec.md`                                                   |
| `..\docs\spec.md`<br>`../docs/spec.md`                                                                                 | Both    | Relative path (parent traversal)        | `mdview:file:///<BASE_DIR>/../docs/spec.md` *(then canonicalize to remove `..`)*                  |
| `C:\docs\spec.md`<br>`C:\My Docs\spec.md`                                                                              | Windows | Absolute path (drive)                   | `mdview:file:///C:/docs/spec.md`<br>`mdview:file:///C:/My%20Docs/spec.md`                         |
| `\\server\share\docs\spec.md`<br>`\\server\share\My Docs\spec.md`                                                      | Windows | UNC path (network share)                | `mdview:file://server/share/docs/spec.md`<br>`mdview:file://server/share/My%20Docs/spec.md`       |
| `\\localhost\share\docs\spec.md`<br>`\\localhost\share\My Docs\spec.md`                                                | Windows | UNC path (loopback share)               | `mdview:file://localhost/share/docs/spec.md`<br>`mdview:file://localhost/share/My%20Docs/spec.md` |
| `file:///C:/docs/spec.md`<br>`file:///C:/My Docs/spec.md`<br>`file:///C:/My%20Docs/spec.md`                            | Windows | `file:` URL (local drive)               | `mdview:file:///C:/docs/spec.md`<br>`mdview:file:///C:/My%20Docs/spec.md`                         |
| `file://server/share/docs/spec.md`<br>`file://server/share/My Docs/spec.md`<br>`file://server/share/My%20Docs/spec.md` | Windows | `file:` URL (UNC/share form)            | `mdview:file://server/share/docs/spec.md`<br>`mdview:file://server/share/My%20Docs/spec.md`       |
| `C:/docs/spec.md`<br>`C:/My Docs/spec.md`                                                                              | Windows | Absolute path (drive, forward slashes)  | `mdview:file:///C:/docs/spec.md`<br>`mdview:file:///C:/My%20Docs/spec.md`                         |
| `//server/share/docs/spec.md`<br>`//server/share/My Docs/spec.md`                                                      | Windows | UNC-like (forward-slash form)           | `mdview:file://server/share/docs/spec.md`<br>`mdview:file://server/share/My%20Docs/spec.md`       |
| `/home/user/docs/spec.md`<br>`/home/user/My Docs/spec.md`                                                              | Linux   | Absolute path (POSIX)                   | `mdview:file:///home/user/docs/spec.md`<br>`mdview:file:///home/user/My%20Docs/spec.md`           |
| `file:///home/user/docs/spec.md`<br>`file:///home/user/My Docs/spec.md`<br>`file:///home/user/My%20Docs/spec.md`       | Linux   | `file:` URL (POSIX)                     | `mdview:file:///home/user/docs/spec.md`<br>`mdview:file:///home/user/My%20Docs/spec.md`           |
| `~/docs/spec.md`<br>`~/My Docs/spec.md`                                                                                | Linux   | Home-relative path (renderer-dependent) | `mdview:file:///<HOME_DIR>/docs/spec.md`<br>`mdview:file:///<HOME_DIR>/My%20Docs/spec.md`         |
| `$HOME/docs/spec.md`<br>`$HOME/My Docs/spec.md`                                                                        | Linux   | Env-var path (renderer-dependent)       | `mdview:file:///<HOME_DIR>/docs/spec.md`<br>`mdview:file:///<HOME_DIR>/My%20Docs/spec.md`         |

`<BASE_DIR>` = the directory containing the current Markdown file, expressed as a file-URL path segment (Windows example: `C:/repo`; Linux example: `home/user/repo`). `<HOME_DIR>` similarly (e.g., `home/user`).
